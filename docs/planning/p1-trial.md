# P1：试用版方案

2026-10-18 对齐定稿（用户拍板三个决策后）。P0 收口（PR #61/#62 合并、E1-E4 真机全过）后的第一优先级：把工程完成度转化为非开发者能感受到的产品价值。界面基座已就位（[对话空间五导航](../status/conversation-space.md)，#63）。

## 目标与完成标准

非开发者**不用终端、不靠口头指导**：完成首次交流和一个任务；手机经局域网直连可用。

- "一个任务" = 本机文档任务（不依赖手机链路）
- 验收主体是**非实现者**（1-2 位未见过项目的人），不是开发自查

## 已拍板的三个决策（2026-10-18）

| 决策 | 选择 | 含义 |
|---|---|---|
| 手机是否进试用 | **进，局域网直连** | 桌面内嵌服务，手机同 WiFi 直访；不走公网，异地不可用如实告知 |
| 模型额度来源 | **自带 key + 预设强化** | 零成本零滥用；试用者需自行注册充值，招募话术明确此前置 |
| 安装包签名 | **P1 不签名 + 如实引导** | SmartScreen 拦截用截图步骤引导；证书属商业发布阶段 |
