# P1：试用版方案

2026-10-18 对齐定稿（用户拍板三个决策后）。P0 收口（PR #61/#62 合并、E1-E4 真机全过）后的第一优先级：把工程完成度转化为非开发者能感受到的产品价值。界面基座已就位（[对话空间五导航](../status/conversation-space.md)，#63）。

## 目标与完成标准

非开发者**不用终端、不靠口头指导**：完成首次交流和一个任务；手机经局域网直连可用。

- "一个任务" = 本机文档任务（不依赖手机链路）
- 验收主体是**非实现者**（1-2 位未见过项目的人），不是开发自查

## 已拍板的三个决策（2026-10-18）

| 决策 | 选择 | 含义 |
|---|---|---|
| 手机是否进试用 | **进，局域网直连** | 桌面内嵌服务，手机同 WiFi 直访；不走公网，异地不可用如实告知 |
| 模型额度来源 | **自带 key + 预设强化** | 零成本零滥用；试用者需自行注册充值，招募话术明确此前置 |
| 安装包签名 | **P1 不签名 + 如实引导** | SmartScreen 拦截用截图步骤引导；证书属商业发布阶段 |

## 增量切分（按依赖排序）

### P1-a 桌面试用闭环（先行，无架构依赖）——工程侧已完成（2026-10-18）

- onboarding 指南对齐五导航（#64：设置→预设→Key→测试连接→聊一聊的真实路径）
- 模型配置**测试连接**（#64：1 token 最小请求，分类=网络不通/密钥被拒/地址有误/HTTP码+服务原话）；语音服务测试（可达性+密钥状态）
- 模型/语音不通时的恢复指引即分类文案本身
- 验证：真实 profile 探测两条分支通过（✓ 成功；假模型名 → ✗ HTTP 400 + 服务原话截断）；NSIS 验收包 8/8 安装生命周期通过（`installer-p1a-20261018b`，含 #63/#64 内容；安装冒烟脚本随协议 v3 修复）
- **待 P1-c**：非实现者干净账号走全流程（含真实 key 首次交流与本机文档任务）——P1-a 不宣称用户体验门已过

### P1-b 局域网手机接续（承重变更：设计文档先行 + 对抗审查）

- 桌面进程内嵌协调服务（倾向进程内挂 Axum 路由而非 sidecar exe——分发简单、生命周期一体；设计文档对比定案）
- **本地账号替代邮箱 OTP**：试用形态下"账号"就是这台电脑，自动生成本地账号；手机经六位码获得信任。SMTP/邮箱体系整个不用（保留给未来云接续）
- 手机浏览器开 `http://<电脑IP>:<端口>` → 配对 → 任务确认/跨端记忆（E1-E4 的局域网版）
- mobile-web 生产化：静态页由内嵌服务直接出（去掉开发态 server.mjs 网关）
- 防火墙首次监听弹窗引导 + 面板实时显示当前地址与配对码
- 边界如实：仅同 WiFi；IP 变了回面板重看
- 完成标准：手机连上 → 任务确认 → 跨端记忆可见

### P1-c 试用验收

- 非实现者在独立 Windows 账号/设备走[首次使用验收单](../quality/first-use-acceptance.md)
- SmartScreen 引导（"更多信息→仍要运行"截图步骤）放进招募说明最前
- 卡点记录 → 修复 → 复验，直到完成标准成立

## 主要风险（如实）

1. **P1-b 账号模型重构**是最大不确定项：登录语义从"邮箱 OTP"变"本地账号+配对码信任"，涉及协调库账号/会话/配对/记忆同步的挂载维度——必须设计先行，不得直接动代码
2. 局域网直连的防火墙/多网卡/IP 漂移是体验摩擦点，引导文案兜底而非消除
3. 自带 key 意味着试用者先注册充值——招募话术明确，避免"开箱即用"误导
4. 未签名包的 SmartScreen 拦截是第一印象摩擦
