# 首次使用与干净设备验收单

配套[T07交付记录](../status/first-use-guide.md)和[测量协议](verification-protocol.md)。本单是执行要求，不表示已获得独立用户或新设备结果。

## 准入

记录提交SHA、构建哈希、Windows/WebView2版本、设备和缩放比例、测试人及日期。安装验收须先具备可安装产物和明确的安装/卸载数据保留策略；当前只有可执行文件，因此安装门保持未通过。使用测试资料及测试服务，明确调用额度；不共享密钥。

## 场景与准出

| 场景 | 必须观察的结果 | 当前证据 |
|---|---|---|
| 全新资料首次启动 | 角色可找到，不抢焦点；点击出现指南；设置/跳过可见 | 本机独立应用目录、原生及浏览器通过 |
| 设置模型 | 由指南进入设置，地址/模型自选，密钥原生输入；不会自动发请求 | 原生无Key本地服务通过；本轮未重测真实凭据输入 |
| 首次聊天 | 显示真实等待/回复/失败；未配置时有说明，不伪造回答 | 本地服务完整链及既有浏览器回归；新设备待测 |
| 重启 | 完成指南不重复；未完成可再次打开；完整问答恢复，半截不恢复 | 原生进程重启及单元/浏览器通过 |
| 删除 | 清空全部模型记录；失败保留旧记录并提示；重启仍为空 | 原生、存储与浏览器通过 |
| 找回与退出 | 拖动、隐藏、安静后托盘恢复；右键找回/退出；退出后无残留进程 | 引导文案已提供；本轮目标新设备人工操作待测 |
| 安装生命周期 | 无开发工具的目标设备安装/启动/升级/卸载；依策略保留或删除资料 | 无安装包，未执行 |
| 环境矩阵 | 主测量协议要求的设备数、混合缩放、多屏/拔插和休眠恢复 | 未执行，不以当前单机测试替代 |

结果须逐项标记通过/失败/未执行并附原始证据，失败关联修复提交和回归结果。所有必测项通过且有独立体验复核后才申请T07完整准出；安装包、账号与商业阶段门另行评审。

## 本机独立资料复核

在工作区根目录构建隔离标识版本（仍不是安装包）：

```powershell
npm run tauri --workspace @companion/desktop -- build --no-bundle --config src-tauri/tauri.acceptance.conf.json
```

该构建的资料进入`dev.qiban.companion.acceptance`，不能当生产版本分发。复测使用独立测试Windows账号或明确空的实验资料目录，不删除或覆盖生产数据。实验模型用无Key本地服务，避免触及按地址保存的真实凭据。记录首次→设置→发送→退出→重开→清空→再重开的结果。

复核结束运行`npm run build:desktop`恢复默认生产标识。测试图像、进程信息和本机辅助文件只放忽略的`.cache`；不要将测试资料、密钥或可执行文件提交到Git。
