# 原生桌面接续同一伙伴

2026-09-25。使用范围：Windows 原生桌面与手机 Web 连接同一台电脑上的协调服务。实际验证及未完成项见[交付记录](../status/desktop-account.md)。

## 启动与登录

在工作区根目录分别打开终端：

```powershell
npm run coordinator
npm run desktop
npm run mobile:https
```

已有对应服务运行时复用即可，不重复启动。协调服务首次配置及受邀邮箱见[启动指南](coordinator-auth.md)；手机 HTTPS 入口见[手机指南](mobile-web.md)。公网链接转发到本机服务，电脑与服务需保持运行。

1. 点击桌面角色 →「任务面板」→「账号与共享待办」。也可由系统托盘打开面板。
2. 填写与手机相同的受邀邮箱，点击「获取登录验证码」，输入邮件中的 8 位验证码，再点击「登录并接续伙伴」。桌面和手机分别申请验证码，申请至少间隔 60 秒；验证码有效期 10 分钟。
3. 对照两端的账号 ID 与伙伴 ID，应完全一致。无需手工复制 ID 或会话令牌。
4. 在「新增共享待办」创建一条记录，另一端点击刷新，或等待可见页面约 10 秒自动更新；从另一端取消后再核对。
5. 退出桌面程序并重新打开，在会话仍有效且协调服务在线时自动恢复。当前服务会话最长 24 小时、空闲 30 分钟过期，过期后重新登录。

构建后的桌面入口为 `target/release/companion-desktop.exe`，使用 `npm run build:desktop` 更新。浏览器预览 `npm run dev` 不支持原生账号登录；手机网页登录使用独立的手机入口。

默认桌面连接 `http://127.0.0.1:4318`；更改后端端口时，先退出账号，再在「本机账号服务连接」修改。此处填写协调服务 API 端口，不是手机 Web 端口或隧道网址。

## 退出与断线

- 「退出此桌面会话」撤销本机会话，手机可继续使用；「退出所有设备」需要确认，服务端成功后其他会话失效，在下一次请求时清除身份显示。
- 离线退出先把撤销意图保存到系统安全存储，立即清空界面的伙伴和共享待办；恢复连接后重试撤销。重开程序也不会把待撤销会话恢复成已登录。
- 凭据存储写入失败会显示「退出未完成」，不能认为退出成功。服务端撤销尚未确认时也不会宣称其他设备已经退出。
- 如果全局退出时本机会话已经失效，只能确认本机失效；界面提示重新登录后再次执行全部退出。
- 协调服务不可用时显示错误；启动服务后点击「刷新账号」。不会改用本地待办冒充共享数据。
- 创建待办响应丢失时，同一界面、同一标题的重试复用请求 ID 防止重复创建；关闭/重开界面后先核对列表，再决定是否重试。

## 数据与跨系统边界

账号、伙伴映射和共享待办保存在协调服务数据库；桌面既有本地待办、聊天、记忆、模型配置与外观仍保存在原有本机位置，不自动上传或合并。普通共享待办只记录，不触发电脑执行。

桌面的 `account-settings.db` 仅保存安装实例 ID 和回环端口。会话令牌与待撤销标志通过 `SessionVault` 接口读写安全凭据存储，令牌不传给前端，不写入配置、SQLite 或导出文件。

当前适配为 Windows 凭据管理器，作用域包含安装实例和服务端口，与模型密钥分开。macOS Keychain / Linux Secret Service 适配尚未实现；不支持的平台明确报错，不回退到明文文件。

**跨系统接续依赖同一账号服务，不依赖复制令牌。** 新设备重新登录后可获得相同伙伴身份；但本轮原生连接仅支持本机回环地址，还没有远程协调服务地址配置。换电脑重新建立一个空的协调数据库会得到另一份账号/伙伴映射。协调服务迁移与备份恢复、原生远程 HTTPS 接入需后续单独实现；仅复制桌面安装目录不能迁移这些数据。

## 工程验证

```powershell
npm run test:desktop-account
npm run test:browser
```

第一条构建手机页面并验证 Rust 原生账号模块、真实 Windows 凭据管理器、独立手机尺寸 Edge 页面与真实协调 HTTP/SQLite 的组合。验证码使用内存测试邮箱，不读取真实 SMTP 设置，不发送邮件，不触碰用户账号数据库。为遵守真实服务限流，跨端用例会等待约 61 秒。需要 Windows、Edge、Node.js 和 Rust 环境。

第二条验证桌面界面交互，账号 IPC 为受控替身；不能代替真实 Tauri 窗口验收。完整人工验收：真实邮箱登录 → 双端核对伙伴 → 交叉新建/取消 → 桌面重开 → 离线退出/重开不复活 → 恢复服务撤销。执行后记录设备、构建、网络及结果。

后续增量已加入[电脑与手机配对入口](device-pairing.md)，配对关系与账号登录、普通共享待办分别管理。
