# 电脑与手机配对体验指南

2026-09-26。先完成[桌面账号登录](desktop-account.md)与[手机 HTTPS 联调](mobile-web.md)，两端登录同一服务、同一受邀邮箱。

## 更新与运行

旧服务需要重启才能提供配对接口。先在旧协调服务终端按 Ctrl+C 正常结束，再从根目录运行 `npm run coordinator`；脚本重新构建并启动服务，启动时自动迁移账号库。不要删除账号数据库，否则会丢失原来的伙伴映射。升级到当前 schema 4 后，旧版本程序不能直接读取此库。

桌面使用 `npm run desktop`，或先 `npm run build:desktop` 再运行 `target/release/companion-desktop.exe`。已打开旧版桌面时，从托盘退出后重开新版。重新运行 `npm run mobile:https` 更新手机网关和页面；Quick Tunnel 可能生成新网址，应使用终端最新输出的链接。

## 配对步骤

1. 电脑点击角色 → 任务面板 → 账号与共享待办 →「设备配对与权限」。填写电脑名称，点击「生成五分钟配对码」。
2. 手机打开「连接电脑」，输入电脑显示的 32 位配对码，填写手机名称，点击「核对电脑与权限」。当前没有扫码入口。
3. 核对电脑名称、标识和权限说明，确认是自己发起的配对，点击「确认配对这台电脑」。权限只有文档摘录协作，每个动作仍需另行确认。
4. 两端点击「刷新配对」，或等待页面可见时约 10 秒刷新，应显示相同关系和“已配对”。页面只显示配对状态，不表示电脑执行器在线。
5. 从任一端撤销关系，另一端刷新应显示“已撤销”；旧码不能再次使用。其他账号不能用此码连接。

**当前可以配对、撤销，以及确认电脑分享的文档摘录并保存新草稿。** 配对不上传文件、聊天或记忆；原有共享待办仍只记事。撤销某个配对关系不会退出账号或删除共享待办，也不会撤销该设备的其他配对关系；设备丢失时可在账号面板执行“退出所有设备”。

配对绑定本次登录。任一端退出、会话绝对过期或空闲过期后，旧关系失效；重新登录同一账号会找回伙伴，但需要重新配对。当前系统未建立长期设备密钥。名称在该会话首次登记后保持不变。

## 异常与验收

- 超过五分钟、重新生成、接受或撤销后，旧码失效；重新生成只能在电脑操作。
- 确认响应丢失：先刷新配对列表核对；不要反复生成新关系。服务端不会允许已消费码再次使用。
- 撤销失败或断网：界面保留失败提示，不能认为服务端已撤销；恢复连接后刷新并重试。必须在线才能完成配对撤销。账号的离线退出流程仍按原指南处理。
- “配对服务不可用”或接口 404：确认协调服务和手机网关均已重启到本轮代码。
- 每账号最多保留 100 条配对记录；本轮没有历史清理界面。此限制避免无限创建，不代表生产设备额度方案。

人工验收记录电脑/手机系统和浏览器、构建、网络、登录/配对/撤销/重开结果。工程自动化入口为 `npm run test:desktop-account`，使用内存测试邮件及独立数据库，不发送真实邮件；包含约 61 秒的验证码冷却等待。

底层协议与动作门禁见[授权设计](../architecture/device-authorization.md)，本轮实际测试见[交付记录](../status/device-pairing.md)。
