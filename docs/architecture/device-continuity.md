# 手机接续同一个伙伴：实施设计

2026-09-21。本文是 O3/T21～T24 的实施方向，未实现能力保持设计状态。首个实际增量见[T16本地执行台账](../status/local-document-execution.md)，总体依赖见[交付待办](../planning/delivery-backlog.md)。

## 职责与身份

手机 React/TypeScript 前台网页承载角色、交办、进度、确认；电脑 Tauri/Rust 负责本地授权范围内的执行；云端服务协调账号、设备、授权、任务事件与同步。建议先一个 Rust/Axum 服务和 PostgreSQL，电脑主动建立出站连接，不开放用户电脑公网端口。手机后台通知仅提示有更新，重新进入页面必须从服务端补齐状态。

account_id 表示数据归属，companion_id 表示稳定伙伴，device_id 表示手机或电脑，conversation_id/task_id 表示接续上下文。角色设定和显式选择的记忆可跨端；位置、透明度等外观偏好默认按设备保留。导入的用户 Live2D 文件不因配对自动上传。将来语音要用有期限的发声端占用标识，切换失败不承诺两端绝不短暂重叠。

首版手机操作需要电脑处理的任务时，电脑离线明确排队。文字模型密钥仍留电脑；云端独立模型调用需单独设计凭据、费用与授权。跨端身份不要求把两端所有数据或权限复制。

## 配对与授权

依 T41 复用托管身份服务；设备分别持有可撤销会话。已登录电脑发起短时、一次性的配对请求，绑定账号、设备和权限范围；手机登录、扫码、核对设备及确认信息后绑定。二维码不携带长期令牌或模型 Key。每次 API 访问由服务端推导用户并核对 owner，不能信任客户端传入的 account_id。

配对只是设备身份。查看、交办、确认、访问资源和记忆管理分别授权。确认绑定 action_id、参数摘要、资源版本、授权版本、有效期；内容变化重新确认。服务端动作准入与撤销顺序可判定，执行端在副作用前检查准入凭据。撤销后拒绝新准入；已准入动作按在途处理，执行中取消必须等待核对，不承诺即时回滚。设备丢失可单独撤销，也要覆盖排队消息与旧凭据重放。

协议选择参考 [RFC 8628](https://www.rfc-editor.org/info/rfc8628/) 与跨设备威胁指南 [RFC 10027](https://www.rfc-editor.org/rfc/rfc10027.html)；仅照搬二维码界面不足以建立授权安全性。

## 执行与断线

任务含 task_id，执行尝试含 attempt_id，副作用含 action_id；命令带幂等键，动作结果和事件持久化。传输允许重复，不宣称通用 exactly-once；执行器通过目标服务幂等机制或具体产物核对减少重复副作用。结果不确定时保持 unknown，而非盲目重试。

业务变更与 outbox 事件同事务保存；服务端分配单调事件游标，客户端应用后持久更新游标。重连补发、去重；超出事件保留窗口返回完整有效快照及新同步代际，不按设备时钟做最后写入覆盖。WS 和推送不是事实来源；服务端重启后从数据库恢复队列和授权。

本机台账已有状态＋事件事务、单动作核验与重开恢复；尚无网络 outbox 派发、服务端游标、云端租约、账号授权。不能直接把新增本机 IPC 暴露到公网。

## 删除不会被旧数据恢复

服务端维护 memory_id、revision、memory_epoch、删除标记和 sync_generation，与已有本机 context_epoch 分工，不把各设备独立计数直接比较。

删除事务清理正文和引用、递增记忆版本、保留无正文的最小删除记录。设备重连先应用撤销/删除，再恢复上传和执行；旧版本编辑与旧 ID 复活请求拒绝。失效前文、摘要、检索缓存及在途生成也需处理，避免旧内容换新 ID 回流；首版可沿用现有有限记忆的清空相关聊天策略。

删除标记只有在所有有效设备确认后，或旧设备的同步资格已作废并要求完整重置后才可压缩。备份恢复先补齐独立保留的删除、撤销和去重记录，再开放执行；不能证明版本足够新则保持暂停。

离线设备无法即时收到删除。UI区分“云端已删除”和“某设备待同步”；要保证删除后无新的旧记忆使用准入，离线端暂停同步记忆的模型使用，恢复在线核验后继续。此前已准入并发出的模型请求不能撤回供应商收到的内容，迟到结果必须丢弃。

## 逐步交付与门禁

| 增量 | 对应工作包 | 准出证据 |
|---|---|---|
| 受限本地执行 | T16、T17局部 | 真实产物、确认、去重、失败/未知、重开核验；已有局部实现 |
| 账号与隔离 | T41/T42 | 两账号交叉访问负测、登录/退出/恢复、不泄露凭据 |
| 动作授权与配对 | T44/T21 | 一次性配对、授权范围、排队撤销、旧令牌/确认重放拒绝 |
| 手机前台交办 | T22 | 离线排队、重复提交、确认/取消、真实进度和结果 |
| 记忆与伙伴接续 | T23/T24/T47 | 删除不复活、长时离线、旧快照/备份恢复、发声端切换 |

首条完整跨端场景为“手机交办指定文档 → 电脑生成草稿 → 手机预览与确认 → 电脑保存 → 手机查看产物”。当前本地版本只接受用户选定文本并生成固定摘录；语义摘要、目录长期授权、云端附件及手机端均需后续实现与验收。

未为未来功能预建空目录。真正落地手机或协调服务时再按职责新增工作区；共享 contracts/core 不反向依赖 apps。部署、服务账号与费用选型在具体配置可审查后再完成，不把示意架构算作已上线。
