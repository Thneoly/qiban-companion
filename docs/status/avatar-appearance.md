# 2D 数字人与轻量场景

2026-09-21。接续[背景拖动](pet-scene-drag.md)，属于 T02/T03/T07/T08 的本机体验增量；不表示这些工作包或商业发行整体准出。

## 用户可用能力

- 点击角色 → **角色与场景**。默认背景改为 242×64 CSS px 的半透明小舞台，完整家园仍可选；原家园背景为 308×428。舞台背景边界面积减少约 88%，原生窗口仍为 320×440 以容纳气泡。
- 三种场景：悬浮舞台、无背景、完整家园。背景不透明度 0～100%，默认 65%；角色和气泡保持清晰。滑块释放或键盘操作完成后保存。
- 舞台用椭圆、渐变和投影形成 2.5D 层次，没有引入 3D 引擎。背景 0% 或无背景时移除背景命中区域；角色仍能拖动。可见背景与角色都是拖动区域，输入和按钮保持正常交互。
- 原创 SVG / **2D 数字人**切换。导入含一个 `.model3.json` 的完整本地文件夹，支持所需 moc3、PNG、物理、姿势、表情和动作资源。不要求用户手动复制 SDK。
- 单个模型本机保存、退出重开恢复、移除本机副本；替换导入前先验证，失败显示原因。原始文件不改动。渲染失败回退 SVG；再次选择数字人可重试，移除后不再恢复模型。
- 文字状态复用当前 companion state。模型作者可使用同名动作组/表情 `attentive`、`thinking`、`responding`、`pleased`、`paused`、`concerned`，状态变化时调用；未提供时保留待机并显示文字状态。没有把通用待机称为专属表情，也没有语音口型。
- Canvas 180×260、最高 30 fps、像素比上限 2；安静、隐藏文档、系统减少动画暂停更新与绘制，隐藏角色/切回 SVG 销毁渲染实例。

## 存储与导入边界

[avatarStorage](../../apps/desktop/src/features/companion/avatarStorage.ts)在应用 WebView2 的 IndexedDB `qiban-avatar` v1 中保存一份外观与模型，独立于 Rust 的任务/聊天/记忆数据库。浏览器预览也持久保存这类外观数据，仍不调用模型服务。不同浏览器来源或应用资料目录不会自动共享；清除 WebView 数据会清除外观副本。与源目录脱钩，后续原文件变更需要重新导入。

上限：256 个文件、总 80 MB、单引用文件 20 MB，模型描述 1 MB、动作/物理 JSON 4 MB；最多 8 张 PNG，每张最大 4096×4096、总像素不超过 32 MP。此首版仅支持一个 Cubism model3 模型，不支持 ZIP、Cubism 2、远程地址或任意目录向上引用。

只复制实际引用的模型资源；忽略目录中的脚本，去除动作音频引用。渲染器覆盖资源解析，所有资源只能取自导入生成的 Blob URL。CSP 的 connect-src 增加 blob，script-src 仍仅 self 和 wasm-unsafe-eval。导入内容不上传、不改变模型供应商配置、不接触凭据。

## 构建和发行边界

开发/构建前自动准备固定哈希的四份渲染运行库及许可声明；清单为[live2d-runtime-manifest](../../apps/desktop/scripts/live2d-runtime-manifest.json)。安装模式关闭 public 任意复制，仅按白名单输出运行库及声明，产物检查重新核验哈希；**不打包 Hiyori 或用户模型**。已有资源可离线使用，干净构建首次准备需要网络。

当前只作内部开发验证。根据 [Live2D 官方发行许可说明](https://www.live2d.com/en/sdk/license/)，开发/试验与发行许可不同，个人和小企业的通常豁免不覆盖 Expandable Applications；官方对 AI/chatbot 也要求先判断该类别。此处允许用户载入模型，需要在对外发行前确认类别及相应授权，不能因没有捆绑角色而认为 SDK 发行条件已解决。角色自身的使用权另行确认；SDK、首发角色授权和资源性能基线仍是 T03 的剩余门禁。

资源解析与手动更新方式依据[维护者的模型文档](https://guansss.github.io/pixi-live2d-display/models/)。运行库版本不在本轮升级。
