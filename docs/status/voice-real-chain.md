# T04 余项：真实语音全链验证

2026-10-07。分支 `fix/voice-tts-output-wav`，接续[T04受控链记录](voice-chain-spike.md)。**真实「麦克风→ASR→文字回复→TTS→播放」全链在智谱云端跑通并核对账单；期间发现并修复智谱 WAV 头兼容缺陷。T04 的服务选择与成本门已过；噪声/回声与多服务商矩阵仍无证据，不据此宣称 T11/T12 可交付。**

## 服务选择

- 本地 vLLM（5080 16G）与云端之间选择云端：少维护一套推理栈，协议与既有 `/audio/transcriptions`、`/audio/speech` 兼容路径一致。
- 智谱通用语音地址 `https://open.bigmodel.cn/api/paas/v4`（非 Coding 文字地址，429 教训见受控链记录）；ASR `glm-asr-2512`（multipart，≤25MB/≤30s 与产品限制一致），TTS `glm-tts`（JSON，`response_format=wav` 非流式），音色 `tongtong`。产品「填入智谱语音示例」预设与官方参数一致，未为此改产品代码。
- 语音地址独立于文字服务，密钥按地址隔离保存在 Windows 凭据管理器；文字阶段走桌面当前文字服务配置，本轮未改动。

## 发现与处置

| 发现 | 处置 |
|---|---|
| 智谱 glm-tts 返回的 WAV 把 RIFF size 字段写为 len-12（差 4 字节），fmt 与 data 间插入 `AIGC`（JSON 水印）与 `LIST` chunk；输出校验的 RIFF size 相等检查误拒。「浏览器能放、程序拒」是该坑特征 | 删除相等检查，长度一致性由 chunk 遍历权威保证（data size 撒谎或截断仍被拒）；校验失败时落盘诊断副本并报头 48 hex（`d5d0f10`）；短 RIFF size 与水印 chunk 各加回归（`4425558`） |
| 输入与输出校验共用同一句错误文案，首次失败无法分辨是哪一侧 | 诊断副本+头部 hex 定位到输出侧；错误文案仍统一（不泄露内部细节），定位靠诊断文件 |
| 播放开头有「du dudu」提示音 | 能量包络分析（20ms 帧 RMS）：开头三段恒定幅度音调（约 0-120/280-660/1340-1480ms）加静音，为服务端合成自带，非产品行为；T11/T12 选型时按服务端特征评估 |
| 播放结束不能重播；选择文件后界面仍显示「未选择文件」（刻意清 input value 以便重选同一文件的副作用） | 本轮修复：complete 后可重播（不发新请求，首播「提交至播放」保持首轮值，停止/新录音/新运行仍释放资源）；准备提示与结果表回显已准备文件名 |
| 失败/停止轮仍计费 | 如实按账单记录，「在途调用可能计费」提示为真实语义，不改成退款承诺 |

## V1～V5 实测

| 验证 | 结果 |
|---|---|
| V1 真实麦克风全链 | 2.58 秒语音「你好，一二三」：识别/生成/合成 314/866/1894 ms，提交至播放 3117 ms，输出 7.39 秒，文本 140 tokens，播放与结束事件正常 |
| V2 WAV 文件路径 | 6.55 秒测试文件：443/1082/3836 ms，提交至播放 5433 ms，输出 14.61 秒，212 tokens；文件名回显改进后复测通过 |
| V3 麦克风权限 | 系统权限关闭时明确报错不卡死；开启后恢复正常采集 |
| V4 停止与迟到 | 播放中可停止，立即停本地录音/播放并请求取消网络；迟到结果不播放 |
| V5 账单 | 控制台 0.041032 元/4 次调用，对应 2 轮×(1 ASR+1 TTS)；其中含被本地 WAV 校验拒绝的轮次——**本地拒绝不等于服务端不计费**。当天账单页数字与本地发起轮数不完全同步（可能统计延迟），按账单页为准，不强行对齐 |

延迟为单次样本，不是分位数矩阵；文字生成耗时走文字服务，不计入智谱语音账单。

## 边界

- 单服务商、单音色、单日样本（智谱/tongtong/2026-10-07）；不构成多服务商或声学环境矩阵。
- 噪声、回声、多说话人、多设备麦克风未测——属 T11/T12 与真实设备验收范围。
- 语音费用接口不返回金额，按控制台事后核对；未把单价反推进产品。
- 文字阶段回复质量未按 Q6 口径评分；语音链不写入聊天历史的设计未变。
- 「du dudu」提示音属服务端行为，产品未消音；若采用需在 T11/T12 处理。
- 未实现：分句流式 TTS、口型、打断、回声处理、桌宠语音状态。
