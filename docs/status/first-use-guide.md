# T07：桌宠首次使用指南

日期：2026-09-17。分支`feat/first-use-guide`，接续本机对话记录分支。本轮完成引导子项，未宣称安装包或干净设备门通过。

## 已实现行为

首次启动仍只显示角色，不自动打开面板或抢焦点。首次点击角色时，在气泡里展示指南：模型配置与主动发送、明文记录保留和全部删除、拖动/收起、托盘唤回与退出。内容可滚动，设置/完成/跳过按钮固定在可见底部。

“去设置模型”打开既有模型设置；配置就绪仅代表本机字段与凭据条件满足，不代表远端连接已验证。指南不会自动请求模型、录音或执行任务。“知道了，开始相处”保存完成状态，重启不再自动出现；“先随便看看”仅本次运行跳过，下次启动仍可见。气泡始终有“使用指南”入口，浏览器预览从该入口查看，不冒充持久保存。

读写状态失败时给出提示，写入失败不关闭指南或虚报已完成，仍可跳过使用待办。引导状态并非用户授权记录，也不是隐私条款同意凭据。
