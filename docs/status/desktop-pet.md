# 桌面角色交付记录

本页保留首次透明角色交付记录。后续位置持久化与下一步验收见[位置记忆与下一增量](pet-position-memory.md)。

日期：2026-09-14。用户授权：将默认体验改为桌面伴侣并开始执行。工作分支：`feat/desktop-pet-window`。

## 已实现

- 默认透明无边框、置顶角色窗口，启动时隐藏辅助任务面板；保留自制SVG角色。
- 点击角色打开气泡，快捷保存待办，按需打开任务面板；面板关闭后角色继续驻留。
- 原生拖动把手、透明空白区域鼠标穿透、安静陪伴、隐藏与托盘恢复。
- 托盘左键恢复，右键菜单可恢复、安静陪伴、隐藏、找回主屏、打开面板和退出。
- 工作区边界回收逻辑；窗口能力分别授权；浏览器预览保持独立内存且明确标识限制。
- 沿用SQLite待办存储。没有AI对话、任务执行、语音或手机控制；角色回应是固定文本。
