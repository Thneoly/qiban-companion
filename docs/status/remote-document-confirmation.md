# T44/T21 文档确认与受限执行增量

日期：2026-09-26。承接[配对首轮交付](device-pairing.md)，推进 T22 的具体确认页面。操作见[体验指南](../development/remote-documents.md)。T44/T21、T22 全包及 G3 尚未准出。

## 已实现

- 电脑选择本地 UTF-8 txt/md，生成固定规则摘录；只有明确点击分享后才上传文件名和摘录。同一预览以不可变 actionId、资源版本、参数摘要和配对版本绑定；手机不能指定磁盘路径或改写参数。
- 手机查看具体预览、明确确认、取消或请求停止。桌面轮询受限接口，获得单次准入并在动作前重查授权，使用既有 T16 执行器保存新草稿；核对实际文件哈希后上报结果。
- 远程文档使用独立本地台账和输出目录，存储位于 companion-storage，Tauri 负责组装与调用。原本机文档 IPC 无法访问该台账，不能绕过手机确认。
- 准入响应丢失时不直接执行；产物已发布但回执未送达时重开核对并补报；取消与完成按实际结果呈现，已完成回执不会被后续配对失效改成已取消。
- 协调库 schema 3 → 4；共享文档、资源和授权在同一事务写入。保留既有账号、伙伴、待办、配对。手机网关仅开放文档列表、确认与取消，不开放提交、准入、结果回执。

## 边界与后续

本轮由电脑选定内容、手机确认保存；还没有手机发起任意新任务、文件下载、长期设备密钥、在线能力报告、稳定远程部署或跨端记忆同步。摘录是固定规则预览，不代表完成 T17 智能摘要。

执行后撤销不删除文件；最后一次授权核对与本地写入之间仍可能收到停止请求，结果以实际产物核对为准。手机收到的是电脑报告的核验结果，不是服务器独立验盘。

共享内容保留与容量见指南；目前没有记录清理入口。真实 Tauri + SMTP + 用户手机人工验收、Q8/Q9 独立验证、服务器恢复后撤销/去重一致性仍待完成。CI 按用户要求保持停用。

下一步优先完成上述人工闭环和取消/断线体验，再补设备在线/能力展示与产物访问；不将这一小范围执行扩展成默认任意电脑控制。
