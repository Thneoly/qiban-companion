后续已增加[协调服务与自有邮箱验证码/会话](coordinator-auth-api.md)，下文保留基础增量交付时的边界。

## 实现

- [core身份边界](../../crates/companion-core/src/identity.rs)：`VerifiedIdentity`只由可信认证适配器在完成验证后构造；不支持JSON反序列化，不包含令牌、邮箱或客户端account_id。构造函数只做字段约束，**本身不验证令牌**。原始登录时间与稳定session_id必须由供应商验证后的结果提供，刷新令牌不能改变二者。
- [storage账号仓库](../../crates/companion-storage/src/accounts.rs)：以精确的`issuer + subject`映射内部account_id和稳定companion_id；不同认证来源的相同subject不合并。账号ID由存储生成，不能传入目标账号执行查询。
- 账号内待办支持创建、列表、读取、按revision取消；只是待办记录，不会转交本机执行器。所有查询、更新与幂等键都包含account_id。跨账号读取和取消与不存在统一返回NotFound；创建请求拒绝额外accountId/user_id等字段。
- 同账号重复request_id只有内容一致才返回原记录；不同账号可独立使用相同request_id。每账号最多100条，重复提交已存在记录不受新增容量限制。当前无清理入口或商业配额。
- 每个操作进入SQLite立即事务后重新检查到期时间、会话撤销和全部退出时间，再做账号内操作；没有可以长期缓存的账号访问句柄。过期边界为`now >= expires_at`。单会话退出只影响本会话；全部退出同时写入截止时间并撤销已登记会话，之前未登记的旧会话同样拒绝。
- 全部退出按原始登录时间判断，不按刷新时间判断。新登录必须有新session_id且登录时间严格晚于截止时间；相等时拒绝。重新认证仍得到同一伙伴及待办。时间单位为UTC毫秒，未来登录时间拒绝，当前未设置时钟宽限。

## 数据与信任边界

这是独立SQLite存储基础，schema v1含accounts、account_sessions、account_tasks和应用标识QBAC；不是PostgreSQL生产部署，也未在桌面启动时创建数据库。仅测试打开临时库。误传其他应用库、已有无版本表或更高版本时拒绝，不认领、迁移或上传已有companion.db/chat-history.db/executions.db。原有模型凭据、聊天、记忆和角色配置不变。

真实服务必须每次请求先核验令牌签名或内省、允许的issuer、audience、到期、供应商会话有效性，再调用本仓库。**客户端自称的subject、解码但未验证的JWT、邮箱或请求内account_id都不能用于构造身份。** 本轮没有认证适配器，不能把此库直接包成公网API。类型边界防止误反序列化，不能阻止不可信宿主代码主动伪造构造参数。

当前退出只撤销本协调存储的访问，不等于供应商全局退出。真实适配器还需处理刷新凭据、安全保存、验证码、速率限制、网络失败及供应商退出；提供稳定session_id和原始登录时间是供应商选型/适配的准入条件。没有自动合并账号、找回密码、全账号删除、附件下载、记忆同步或多租户账本。

事务可排序数据库内的待办和撤销；它不是跨设备执行授权，不保证停止已经准入的外部副作用。T44的动作授权版本、配对撤销与执行中停止另行实现。生产还需账号级配额、会话记录保留策略、备份/撤销恢复、时钟与运行监测。

## 验证

本轮新增10项Rust测试：2项领域边界及8项存储测试，使用明确的合成可信身份，不调用供应商，不代表真实登录通过。

- 两账号及同subject不同issuer的列表、读取、取消负测；不暴露他人任务是否存在。
- 幂等键按账号隔离、参数冲突拒绝、取消revision冲突。
- 单会话退出、刷新后仍拒绝、同session更改登录时间拒绝，其他会话继续使用。
- 全部退出覆盖未见过的旧会话及时间相等边界；新登录恢复原伙伴及记录，其他账号不受影响。
- 每种公开操作在过期后拒绝；失败不会写入或误撤销；刷新后原任务仍在。
- 两个独立连接看到已提交的撤销，文件库关闭重开后撤销和伙伴归属仍保留。此项为顺序跨连接测试，不冒称并发竞态/分布式验收。
- 未来/其他schema拒绝且原本机待办保持原样。
- SQLite触发器注入写入失败验证账号和任务一起回滚；容量按账号计算。

实际已通过：`npm run check`（34项TypeScript测试、类型检查及前端生产构建）；`cargo test --workspace --locked`（84项通过、1项既有Windows凭据集成测试忽略，doc-tests通过）；`cargo clippy --workspace --all-targets --locked -- -D warnings`；格式检查、文档/目录/计划检查（44份Markdown、270处本地链接）、8条原型脚本流程通过。未改变桌面入口/渲染/IPC，未运行新的原生登录或手机测试，也没有重建安装包；现有演示程序继续提供上一轮的文档任务。
