## 两种记忆的区别

应用记忆属于栖伴当前应用，个人记忆服务可以供 MCP 客户端和栖伴共同读取。两者在聊天预览与回执中分别显示，选择与预算分别约束；个人条目发送前核对 id/seq 和有效状态，服务侧更正/取代后不静默沿用旧预览。协议已统一为 v3。详见[个人记忆注入](personal-memory-chat-injection.md)。

手机上的共享待办和文档协作不等于记忆同步。当前没有跨设备记忆删除传播的准出证据，不能声称“所有设备已经共享完整记忆”。

1. **完成真实设备联合验收**：桌面与手机同伙伴，配对、文档确认、取消、退出/重开、网络中断；同时检查个人记忆预览、发送、更正后拒绝旧预览，并核对在线状态在约定超时内更新。保留实际设备与结果记录。
2. **补跨设备使用反馈**：~~电脑在线/离线及能力展示~~（已于 2026-09-27 交付，见[设备心跳记录](device-presence.md)）；~~任务进度区分与未知状态恢复入口~~（已于 2026-09-27 交付，见[任务进度记录](task-progress-recovery.md)）；剩余结果访问与记录清理；先把现有受限任务做完整。
3. **回补伙伴体验门**：真实语音全链、角色资源与性能、记忆质量评分、干净设备安装及独立用户体验。无需等新增工具才做这些验证。
4. **再扩工具与商业验证**：根据目标用户的重复任务和付费反馈选择下一种执行能力，补成本、权限、恢复与运营基础。当前不宣称 G3 或商业可售。
