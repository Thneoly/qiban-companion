2026-09-22。接续[账号隔离基础](account-isolation-foundation.md)。用户选择自有账号服务，手机首发采用[Web](../architecture/mobile-client-strategy.md)，App与小程序保留后续入口。本文记录后端增量，未宣称手机界面或配对已经完成。

## 实现与归属

- [apps/coordinator](../../apps/coordinator/Cargo.toml)提供独立Rust/Axum进程、邮箱验证码、SMTP适配、Bearer会话、伙伴查询、账号内待办和退出接口，不依赖Tauri或托管身份平台。
- [认证模块](../../apps/coordinator/src/auth.rs)使用系统随机数、HMAC-SHA256、SHA-256和TLS邮件库。运行时必须提供独立HMAC密钥、SMTP和受邀邮箱；没有明文邮件传输、日志验证码、假身份或绕过验证码的运行开关。
- [原生认证存储](../../crates/companion-storage/src/accounts/native_auth.rs)归companion-storage。协调账号库v1迁移到v2，新增受邀邮箱登录产生的用户映射、验证码摘要/状态、持久限额及会话摘要。现有协调账号/伙伴/任务保留，桌面三个业务数据库不迁移、不上传。
- 验证码10分钟、5次错误限制、一次有效；同邮箱60秒冷却/每小时5次，实例每小时30次。HMAC密钥不进库。邮件成功确认后激活，失败代码不可兑换；新验证码使旧代码失效，成功使用/错误耗尽/作废会清掉验证码摘要。
- 会话令牌由256位随机数产生，数据库仅保存摘要；24小时绝对期限、30分钟闲置期限，无刷新令牌。每次账号访问检查持久撤销和期限。全部退出同时使本账号待用验证码失效，旧令牌不能重放退出或扩大作用范围。
- 核验和待办操作共用账号库的事务边界，跨账号读取/取消返回404，创建请求拒绝自报owner，参数变化的重复请求返回冲突。账号内待办仍不连接桌面执行器，不会自动操作文件。

## 产品与准出边界

运行与限制见[自有账号联调指南](../development/coordinator-auth.md)。服务仅监听本机，暂无HTTPS网关、手机/桌面登录UI、端侧凭据保存或Cookie/BFF、公开注册、设备配对、动作授权、记忆同步、全账号删除、邮件队列、来源IP限额、生产备份及独立安全评审。

数据库明文保存受邀登录的邮箱和必要元数据，验证码及会话令牌仅保存摘要；这不等于数据库已加密。SMTP确认接收不保证最终邮件送达。重开后令牌是否仍有效由服务端状态决定，客户端的安全恢复体验仍待实现。

T41已按用户选择从托管认证调整为自有邮箱验证码/服务端会话；原计划工期估算保留为历史基线，额外邮件运维、滥用防护、安全与恢复工作需重新估算，不宣称原4～6人日能覆盖新增责任。下一增量为真实SMTP验证和手机Web登录/会话管理，然后按T44/T21进入设备授权及配对。本轮仅交付可验证后端子项，T41/T42/T22与G3仍未整体准出。
