# 通用模型设置与 Live2D 实验交付

日期：2026-09-15。基于位置记忆分支的下一增量。实际实现是单机内部样机，不等于T09云端多用户能力或商业阶段门通过。

后续真实模型验收与临时会话已推进，见[最新记录](session-chat.md)。以下保留本增量交付时的状态。

## 本轮能力

- 角色气泡增加“聊一聊”“模型设置”和“Live2D 实验”，待办入口保留，仍不执行任务。
- 设置可编辑 API 基地址、任意模型编码和是否使用 Key。支持兼容 Chat Completions 的云端/本机流式文本服务；智谱是可修改预设，没有把模型或地址写死在传输层。
- 非密钥配置保存到宿主独立 SQLite；Windows 原生密码窗口输入 Key，凭据按 API 地址分别保存。React 和 IPC 返回值只看到配置状态，不能读出 Key。
- 单轮请求、流式输出、明确失败、90秒总时限、停止和旧请求过滤；收起/失焦会停止并清空会话。只有服务返回实际用量才展示 tokens。
- Live2D独立渲染器显式启用，使用本机准备的Hiyori示例；默认SVG，异常回退。安静暂停更新/绘制，隐藏卸载画布。本机资源存在时会被打包，尚无商业分发授权结论。

## 尚未通过的准出项

**真实服务商调用仍待验收。** 用户已确认具有通用API Key，但没有向助手提供密钥；需在应用中配置后，确认账号支持的实际模型编码、正常回复、停止、延迟和用量。`glm-5.3`仅保留用户指定的可修改预设，不声称已验证该型号可用。其他厂商的参数差异同样需实测。

本轮没有语音、口型、情绪动画状态机、长期记忆、会话记录、工具执行、手机控制或摄像头。没有测得可用于资源门的长期CPU/GPU/内存/功耗数据；多屏混合DPI、拔插、系统托盘实点等既有缺口保留。Live2D的示例素材与SDK商业许可尚待确认，自有角色资产仍需制作。
