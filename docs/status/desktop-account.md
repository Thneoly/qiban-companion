# 原生桌面账号与共享待办交付

日期：2026-09-25。对应 O3/T41/T42 的原生桌面增量。[运行与人工验收](../development/desktop-account.md)；[计划与门禁](../planning/delivery-backlog.md)。

## 已实现

- 任务面板增加账号邮箱验证码登录、账号/伙伴标识、共享待办创建/取消、刷新、单会话及全局退出。与原有本机待办明确区分，不自动上传、合并聊天、记忆或任务。
- Rust 宿主连接本机协调服务；端口可在退出后配置。固定回环地址、禁用代理/重定向、限定响应大小；前端只能调用明确的账号 IPC，不能读取令牌或调用任意 HTTP 路由。账号权限仅授予主面板。
- 原生 `SessionVault` 接口与平台适配分离。Windows 凭据管理器保存会话和待撤销意图，按安装实例/端口隔离，与模型密钥分开；配置 SQLite 只保存实例 ID 和端口。
- 重开读取凭据并向服务端核对账号/任务；过期或撤销不返回账号数据。可见页面每 10 秒刷新、重新可见/在线时补查；旧响应不能覆盖退出后的状态。
- 退出先持久化撤销意图；断线时不恢复身份、不允许新操作，重开继续撤销。安全存储失败明确显示退出未完成；全局退出遇到已失效令牌不会宣称其他设备已退出。
- 登录响应/凭据保存失败可用同 nonce 重试；当前界面创建响应丢失可用同 requestId 重试。服务端完成幂等校验。

## 边界与后续

本次没有自动申请用户验证码、读取邮箱、迁移现有桌面数据或触发远程执行。真实 Tauri 窗口 + SMTP + 用户手机的联合人工体验仍需按指南补充。此前手机 Web 的用户确认不自动覆盖本次原生界面。

macOS/Linux 安全存储适配、原生远程 HTTPS 服务地址、正式协调服务迁移/备份恢复、固定公网部署尚未实现。Windows 安全存储不是可迁移的账号数据库；换系统应重新登录同一服务，而非复制令牌。

后续在人工确认闭环后进入 T44/T21 的授权与配对，之后才开放有限手机交办。普通共享待办目前不执行；T41/T42 全包、跨端 Q8/Q9 与 G3 未准出。CI 按用户要求保持停用，不把本机验证写成外部 CI 通过。
