# 对话阅读与生成状态

日期：2026-09-15。分支：`feat/chat-reading`，基于临时多轮会话分支。

输出预算后续已开放配置，见[最新增量](model-output-budget.md)。下述限制发现保留为本轮历史记录。

## 本轮体验

角色气泡新增“展开阅读”，在原来的320×440透明窗口内展开阅读区，不另开任务面板或扩大原生窗口。问答按角色分段显示，已完成记录标注“已加入前文”；输入、停止、清空和“收回气泡”保持在阅读区外。长段落、换行与超长连续文本可以滚动阅读，不引入HTML或Markdown执行。

默认跟随新回复到底部；用户向上翻阅后停止自动跟随，“回到最新”可恢复。收回气泡回到原来紧凑形态，完整收起仍按既有规则停止生成。展开期间角色可能被阅读区覆盖，关闭阅读恢复角色可见范围；拖动把手仍位于底部。

状态区区分准备、等待首段、回复中、完成、停止和未完成，等待期间显示经过的秒数。部分失败回复保留在当前界面，并说明未加入前文；用户可以编辑原问题再发送。没有自动重试。

模型成功但历史读取失败时，保持“已完成”并提示收起后重新打开读取记录，不把它显示成模型请求失败，避免误导用户重复调用。所有界面状态以实际流式事件及结果驱动。

## 验证口径

浏览器新增长文本阅读、手动滚动期间增量到达、返回最新、收回尺寸，以及部分失败与记录读取失败区分的测试。已有临时会话、取消、待办、Live2D回退/加载/暂停和隐藏测试继续回归。

此增量只改桌面前端，没有修改模型地址、型号、密钥、Rust上下文规则、IPC权限或数据存储。真实模型沿用用户保存的配置；后端协议与凭据的既有测试结果见[临时会话记录](session-chat.md)，不重复当成本轮新增Rust测试。

## 下一步的准入与准出

先补齐通用的最大输出预算设置、上限校验和明确的超限反馈，再衡量真实模型的首段等待及完成率；避免把“提高额度”直接等同于问题解决，思考与输出参数需按实际兼容协议验证。

下一轮进入可选的磁盘会话历史前，先冻结：默认是否保存、保留天数/条数、删除范围、关闭保存后的行为，以及“历史记录”和“发送给模型的前文”如何分开。迁移不得把现有临时内容自动写盘；模型/服务切换不能悄悄把旧服务会话发到新服务。

准出至少包括：用户明确选择是否保存；重启后可查看记录；可删除单个会话及全部本机记录；关闭保存和删除后行为可验证；数据库迁移及异常恢复通过测试；说明删除本机记录不等于删除服务商侧内容。长期偏好记忆、语音、工具执行与跨设备同步仍分别排期，不混入本轮阅读优化。
