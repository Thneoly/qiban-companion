# 真实模型验收与临时多轮会话

日期：2026-09-15。分支：`feat/session-chat`，基于通用模型设置分支。保持桌面伙伴入口，不新增云端服务或长期数据库记录。

后续阅读和消息状态改进见[阅读增量记录](chat-reading.md)。以下保留本轮模型与会话验收。

## 用户结果

角色“聊一聊”支持连续问答。最近成功完成的问答保留在Rust进程内，收起气泡、切换待办、隐藏或安静陪伴后再打开可以继续聊。气泡中“最近 N 轮”可查看保留的问答，“清空对话”清除本机前文与当前显示。退出程序再启动即为空会话。

上下文最多6轮、用户与助手文本合计12000个Unicode字符，超限从最早完整问答开始移除。仅成功结束的问答进入前文；失败、截断或停止中的部分回复不进入上下文。收起仍会停止当前生成；已经完成的问答保留。

改变API基地址或模型编码后清空前文。同地址同模型保存不会清空。会话版本校验阻止切换出去又切回时，旧请求把前文重新写入。当前在同一地址更换Key不会自动清空；若更换账号，可先清空会话。

“清空”只针对本机临时会话，不会撤回已经发送到服务商的内容，也不代表服务商侧记录已删除。每次发送会携带保留的前文，实际输入用量可能随上下文增长。密钥仍只由Rust使用，不进入React或会话记录。

## 真实调用证据

使用用户已经在应用中保存的通用Key，通过真实Tauri界面、Rust传输与智谱通用API验证；没有读取或输出密钥。测试输入为固定自我介绍、测试暗号与学习计划请求，没有使用用户文档或待办。测试后清空临时记录，保留用户配置的 `glm-5.3-flash`。

| 模型/场景 | 实际结果 |
|---|---|
| `glm-5.3`，首次单轮验收 | 成功；首段文字约3.04秒，总计约3.95秒，界面观察到7次文本更新，服务返回266 tokens |
| `glm-5.3`，首段前停止 | 约157毫秒回到可输入状态；观察1.5秒无迟到文本 |
| 用户改为 `glm-5.3-flash`，记住测试暗号 | 成功；首段约7.66秒，总计约7.96秒，返回444 tokens |
| `glm-5.3-flash`，收起再打开后追问暗号 | 正确回复首轮暗号；总计约2.94秒，返回170 tokens；此轮首段计时未采集到，不填造数据 |
| `glm-5.3-flash`，已有文本后停止 | 约139毫秒回到可输入状态；观察1秒无迟到文本；历史保持前2轮，部分回复未写入 |
| 查看、清空、重新打开 | 原生界面可查看2轮；清空后宿主与UI均为0轮，重新打开不恢复旧内容 |

以上是少量功能验收样本，不是延迟百分位、稳定性或型号性能对比。token数量是服务响应给出的计数，未推算金额；取消请求没有取得完整用量，费用未知。原始结果和截图在被忽略的.cache目录，不提交真实凭据。

- `npm run check`：类型、6项Vitest与前端构建通过。
- 浏览器8项通过，显式启用本机Live2D示例检查；扩展了停止后再次发送、收起恢复、记录查看与清空的回归。修复了停止按钮在状态快速切换时可能触发表单默认提交的问题。

- Clippy、格式检查、文档与原型检查均通过；Windows release构建通过。

此前真实模型缺口在本账号的上述两种模型上取得功能证据，不能据此宣称所有兼容服务已验收，也不等于云端多用户T09或产品阶段门通过。

## 保留边界与下一步

本版仍没有磁盘会话历史、跨启动记忆、自动摘要、语音、口型、工具执行或手机接续。Live2D仍是可选内部示例；长期资源、多屏和商业素材授权缺口保持。下一增量宜先改善长对话阅读和消息状态呈现，再确定磁盘历史的保留、查看、删除与迁移规则；启用长期记忆需单独设计用户控制。

运行及配置见[开发说明](../development/model-settings-live2d.md)，前一增量见[通用模型与Live2D记录](model-settings-live2d.md)。
