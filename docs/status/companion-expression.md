# T08-TEXT：角色跟随真实文字交流

日期：2026-09-16。分支：`feat/companion-expression`，基于`feat/model-output-budget`。归属[交付计划T08及当前执行对照](../planning/delivery-backlog.md)，服务O1持续相处目标。

## 交付行为

| 真实事件/情境 | 角色表现 |
|---|---|
| 待机、打开气泡 | 待机呼吸；打开后轻微倾身，显示“我在这里” |
| 请求发出，尚无文本 | 思考动作与圆点，显示“正在等回复…” |
| 收到当前请求的文本 | 回复星光与“正在回复你”；没有假装播放语音或口型 |
| 完整回复结束 | 笑眼、两次挥手、“回复写好了” |
| 用户停止接收 | 放松表情、“先停在这里”；迟到文本不复活动作 |
| 回复失败 | 关切眉眼、“回复没有完成”；不播放成功动作 |
| 收起、安静、隐藏 | 收起恢复待机；安静闭眼且停动画；隐藏最高优先级 |

完整回复后的历史读取失败仍保持完成表情，并由原有消息说明记录问题。文字回复完成只代表当前回复结束，不表示替用户完成了实际任务。

展开阅读保留栖栖小形象，与主角色使用相同状态。原创SVG为代码资产revision 2，路径`apps/desktop/src/features/companion/AvatarArtwork.tsx`；使用独立渐变ID支持同屏多个实例。优先级与文本反馈集中在同目录`presentation.ts`，ChatBubble发布已有真实phase；没有新增模型调用、自动重试或推测情绪识别。

系统减少动画设置关闭动画，仍保留表情/文字反馈。Live2D实验沿用现有渲染和安静暂停/隐藏释放机制，共享文字状态反馈；本轮没有绑定示例模型动作、口型或声线，不能算正式Live2D人物表现验收。
